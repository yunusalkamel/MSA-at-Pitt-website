# Partner Logos

Drop transparent-background logo files (PNG or SVG) into this folder, named exactly as listed below. The PartnerLogos component will render them automatically; if a file is missing, the component falls back to a clean wordmark.

Recommended specs:
- White-on-transparent (the strip sits over a light surface and applies a subtle grayscale-on-default, color-on-hover treatment)
- ~200px wide
- PNG or SVG

Filenames:
- attawheed.png    — Attawheed Islamic Center
- icp.png          — Islamic Center of Pittsburgh
- icwp-map.png     — Islamic Center of Western PA / MAP
- mccgp.png        — Muslim Community Center of Greater Pittsburgh
- miftaah.png      — Miftaah Institute
- qalam.png        — Qalam Institute
- almaghrib.png    — AlMaghrib Institute
- pitt.png         — University of Pittsburgh
- cmu-msa.png      — CMU MSA
- duq-msa.png      — Duquesne MSA

Until you upload real files, the strip uses styled wordmark fallbacks — fully functional, just less polished.
